工作两年的我：谈谈想要的职业生涯

我发现我们往往顺着生活的惯性走而不对生活本身有太多反思，这或许是因为这样的反思不仅得不到答案让人痛苦，甚至这种反思还会影响我们现在的生活 举个例子，在高中，那些时常反思“为什么要高考”、“为什么要学习”的人大概率成绩不会比脑海中有“高考改变命运”思想钢印的人好，因为他们花了太多时间去想彼时他们还无法解决的问题，想不清楚自然是内耗 是啊，这样的反思让人痛苦、让人想要逃避，于是顺着惯性走的人绝对是大多数人，当然，也不排除我也是其中之一，毕竟未来的事谁能想到呢，职场两年里，我最大的发现就是原来我如此容易变成我初入职场时看不起的那群人，那群坐以待毙、摇尾乞怜、求天保佑的人 “想想我的职业生涯”这个待办在我待办清单里躺了很久，无数次，我把他放到“要做的事情”清单，又放回“以后再做吧”清单。无数次放到“要做的事情”，是因为职场上见到不同的人被他们所启发，大部分情况是觉得不想成为某人的样子，我也不清楚这是“不甘平凡”还是“自以为是”。而无数次放回“以后再做吧”清单，则是感觉想不清楚，索性逃避吧 《少有人走的路》里面说：逃避痛苦会引发更大的痛苦。果不其然，这个问题没有想清楚，就让人感觉非常迷茫，完全不知道未来在哪里、要怎么走，很多对未来的梦想或者愿景也越发越觉得是空想，进而使得自己内耗严重痛苦不堪。所以我还是得尝试去解答这个问题，并且我确实发现我从进入企业就顺着升职加薪的职场惯性在走，完全没有花时间想想自己真正想要什么 于是工作两年的我来尝试谈谈我想要的职业生涯吧 我不想玩怎样的职场游戏 在谈“想”之前，“不想”是更加明确的一些答案： 我不想玩升职游戏、层层晋升的游戏：在我所处企业的文化里，职级似乎非常重要，年限长职级低意味着能力不行，然而升级本身极其于你的上级对你的看法，我发现我并不擅长这样的游戏，我只能控制自己能不能把事情做好，而无法控制做完事情后别人对我的看法，说实话我也读不懂上司对我是什么态度… 我不想玩混吃等死、有钱赚就行的游戏：我发现能否获得成长是我很在意的事情，如果每天混日子，哪怕工资还行，我也完全受不了 我并不厌恶的一些情况 加班多：如果是做真正有意思的事情，比如为了自己的产品能够更快满足用户需求而加班，这样加班其实一点也不累，比较反感的是强制加班、无效加班、加班文化，比如不加班的人会被认为是不努力 一些梦想中的可能性 remote work：找一份不错的 remote work 然后在家乡住或者出去旅行 清闲工作+open source contribution：那么在拥有一定财富积累之后找一份钱少些但清闲的工作并且参与开源贡献或许是一个可以一直进行到死的生活方式，如果完全财富自由了只进行开源贡献、”为热爱发电“，好像也可以 能不能不工作？ 还有另一个重要的问题就是：”能不能不工作？” 我始终认为人是闲不下来的，工作或者换个说法叫找事情做是必要的，“劳动最光荣”实际上是无比正确的。作为现代人，我们人生中有大量时间都用在工作上（哪怕财富自由也闲不下来，只是有了更多选择权），所以更应该做的是找到自己喜欢做的事情，而不是幻想有一天能不做任何事情 人只有为这个世界贡献价值才能感到自己的价值，才会觉得生活是有意义的，实际上这个价值也不用太大，力所能及即可
